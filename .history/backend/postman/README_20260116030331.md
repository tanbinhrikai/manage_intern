# Weekly Report API - Postman Collection

## 📋 Hướng dẫn sử dụng

### 1. Import Collection vào Postman

1. Mở Postman
2. Click **Import** → Chọn file `WeeklyReport_API.postman_collection.json`
3. Collection sẽ được import với tên "Weekly Report API"

### 2. Setup Environment Variables

Tạo **Environment** mới trong Postman với các variables:

| Variable | Initial Value | Description |
|----------|---------------|-------------|
| `base_url` | `http://localhost:8080` | Base URL của backend API |
| `access_token` | (để trống) | JWT token sẽ tự động lưu sau khi login |
| `intern_id` | `1` | ID của intern để test |
| `report_id` | (để trống) | ID của report sẽ tự động lưu sau khi create |

**Lưu ý:** Sau khi login thành công, `access_token` sẽ tự động được lưu vào environment.

### 3. Test Flow

#### Bước 1: Authentication
```
1. Chạy request "Login (Get Token)"
   - Email: admin@rikai.com (hoặc mentor email)
   - Password: Admin123456 (hoặc password tương ứng)
   - Token sẽ tự động lưu vào {{access_token}}
```

#### Bước 2: Test CRUD Operations

**Create Weekly Report:**
```
POST /weekly-reports
Body (Full example):
{
    "internId": 1,
    "weekStartDate": "2026-01-06",
    "tasksAssigned": "- Task 1: Implement user authentication API\n- Task 2: Create database schema",
    "tasksCompleted": "- Task 1: Completed\n- Task 2: In progress",
    "outputQuality": "Code quality tốt, tuân thủ coding standards",
    "proactivityScore": 8,
    "progressScore": 7,
    "issuesRisks": "Cần hỗ trợ thêm về JWT token refresh",
    "mentorOverallComment": "Intern làm việc tích cực, có tiến độ tốt"
}
```

**Get All Reports:**
```
GET /weekly-reports?page=0&limit=10
GET /weekly-reports?internId=1&page=0&limit=10  (Filter by intern)
```

**Get Report by ID:**
```
GET /weekly-reports/{{report_id}}
```

**Update Report:**
```
PUT /weekly-reports/{{report_id}}
Body (chỉ gửi fields cần update):
{
    "tasksCompleted": "All tasks completed",
    "progressScore": 9,
    "mentorOverallComment": "Updated comment"
}
```

**Delete Report:**
```
DELETE /weekly-reports/{{report_id}}
```

**Get Reports by Intern:**
```
GET /weekly-reports/interns/{{intern_id}}/weekly-reports
```

**Get My Interns (Danh sách intern của mentor hiện tại):**
```
GET /interns/my-interns
GET /interns?page=0&limit=10  (với pagination)
```

### 4. Test Cases

Collection bao gồm các test cases để verify validation và error handling:

1. **Duplicate Report Test** - Tạo report trùng tuần → Expected: Error 400
2. **Invalid Score Test** - Score ngoài range 1-10 → Expected: Error 400
3. **Missing Required Fields** - Thiếu weekStartDate → Expected: Error 400
4. **Unauthorized Access** - Mentor tạo report cho intern không được assign → Expected: Error 403/404

## 🔐 Authorization

Tất cả endpoints (trừ login) yêu cầu:
- Header: `Authorization: Bearer {{access_token}}`
- Role: `ADMIN` hoặc `MENTOR`

**Authorization Rules:**
- **Admin**: Có thể xem/tạo/sửa/xóa tất cả reports
- **Mentor**: Chỉ có thể xem/tạo/sửa/xóa reports của intern được assign (`intern.mentor_id = current_user.id`)

## 📌 Notes

1. **Week Number**: Tự động tính từ `intern.start_date`, không cần gửi lên
2. **Duplicate Check**: Không cho phép tạo report trùng `intern_id + week_start_date`
3. **Score Range**: `proactivityScore` và `progressScore` phải trong range 1-10
4. **Required Fields**: Chỉ `internId` và `weekStartDate` là bắt buộc
5. **Authorization**: Mentor chỉ có thể thao tác với intern được assign
